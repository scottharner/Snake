saturn
------
- why does my tile show garbled when using jo engine and map editor?
	- you cant use compression when saving a graphic as tga
- what is the default resolution with jo engine?
	- 320x240 when JO_NTSC=1
	- 320x224 when JO_NTSC=0 (getting 320x240 for tv dimensions but can only do sprite tiles 320x224)
- what is the difference between jo_sprite_draw3D and jo_sprite_draw3D2?
	- first one uses center aligned coords and the second uses top left coords
- jo_core_init must occur before other jo calls
	- i was mistakenly calling jo_malloc first and then my work was getting clobbered with the subsequent call to jo_core_init
- it looks like tga names might have to be 8 or under and not sure if they can have dashes
- how do i get true random numbers with jo engine?
	- i guess there is no clock for saturn so calling time is useless when trying to seed the random number generator
	- i ended up setting up a counter to increment every draw of the title screen and use that counter to seed once the user pressed start
	- you have to set the seed using jo_random_seed
- what does JO_COMPILE_USING_SGL do?
	- this makes jo engine be a wrapper around SGL
	- if you disable it puts you into an experimental version of jo engine that may be buggy
- are there any other documentation sources other than the official jo engine website
	- https://emeraldnova.com/shrec/joengine000.php
	- example of what could be done: https://github.com/jae686/srl-tutorials/tree/main 
- sound effects
	- i had a surprisingly tough time playing sfx using jo engine
	- with the sample demo i initially played my sound and it was garbled
	- i finally got the settings right in converting from wav to pcm so that i could make out my sound but it still sounded based
	- i ended up having better luck with the potone driver
		- dont load the jo engine audio module when using this
		- you have to be careful about memory usage as i saw it run out when adding just one sound to the demo
		- you can unload sounds by calling pcm_reset
		- if you run out of memory there is a silent failure and no sounds will played
		- to convert with ffmpeg: ffmpeg -i "mySound.WAV" -f s8 -ac 1 -ar 15360 "mySound.PCM"
		- to load the sound in code: mySoundId = load_8bit_pcm((Sint8 *)"PICKUP.PCM", 15360);
		- to play the sound: pcm_play(mySoundId, PCM_PROTECTED, 6);
		- to include posound:
			- download the source from https://github.com/ponut64/SCSP_poneSound
			- grab pcmsys.h and pcmsys.c from the jo_demo example and drop them in your project folder
			- add an include statement in code for pcmsys.h
		- subfolder usage with ponesound requires calling sbl functions which is slow and not recommended so i'll avoid for now
		- need sdrv.bin in cd folder
		- have to add the following two calls in code:
			- load_drv(ADX_MASTER_2304); (needed if not using adx???)
			- jo_core_add_vblank_callback(sdrv_vblank_rq);

genesis
-------
- build is different
	- we do "make" and "make clean" from the genesis folder due to the specific requirements of sgdk
	- we run "run_with_mednafen.bat" from genesis/out (folder names are in required sgdk format)
- we have to be concerned with palettes
	- we have four palettes of 16 colors each (pal0, pal1, pal2, pal3)
	- the last color of each palette is used for text display
	- have to make sure we select the right palette when displaying text or an image
	- mtpaint is useful for setting up your image palette
		- you can save the palette in there and load it for other images
		- have to set your images to 16 color (4 bit) indexed mode
	- the first color in a palette is transparent
	- vdp_init wipes all of the palettes so only do that at the very beginning

general
-------
- we have one make file per platform now, so to make we need to
  - cd into the platform specific build directory
  - run make clean (optional)
  - run make
- we will use a consistent naming convention: snake_case everything except MACRO and ENUMERATION_CONSTANTS
- we use a pointer to store object map so that we only have to allocate the memory that we need for the platform
	- initialize = int *array = (int *)malloc(rows * cols * sizeof(int));
	- access = array[2 * cols + 3] = 42; // row 2, column 3
